About Cybersecurity

Cybersecurity is the practice of protecting computers, servers, mobile devices, electronic systems, networks and data from malicious attacks. Small businesses are increasingly becoming targets because they often lack dedicated security teams. This project demonstrates how a small business can protect its information through a Cybersecurity Policy and an Incident Response Plan.

Cybersecurity Policy

Password Policy

  • Minimum 12 Characters
  • Use uppercase and lowercase letters
  • Include numbers & symbols
  • Enable Multi-Factor Authentication
  • Never share passwords

Device Security

  • Install Antivirus
  • Update Operating System
  • Enable Firewall
  • Automatic Screen Lock
  • No Unauthorized USB Devices

Email Security

  • Verify Sender
  • Don't open unknown attachments
  • Report phishing emails
  • Business use only

Data Protection

  • Encrypt Sensitive Data
  • Daily Backups
  • Limited User Access
  • Strong Access Control

Internet Usage

  • Use Trusted Websites
  • No Pirated Software
  • Use VPN on Public Wi-Fi
  • Safe Browsing Practices

Employee Awareness

  • Cybersecurity Training
  • Phishing Awareness
  • Social Engineering Awareness
  • Report Suspicious Activity
