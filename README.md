# Cyber-Security-Policy-and-Incident-response-plan
A professional web-based project demonstrating a Cybersecurity Policy and Incident Response Plan for small businesses. Built with HTML, CSS, and JavaScript, it presents security policies, response procedures, roles, best practices, and an interactive dashboard in a modern, user-friendly interface..

- Incident Response Plan
